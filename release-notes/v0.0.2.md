# Enshrouded Character Workshop · v0.0.2

**A cleaner start to your next adventure.**

This patch simplifies the save-loading toolbar and introduces curated,
version-specific release notes for every future release.

## ✨ Highlights

- **Simpler toolbar:** removed **Open active index** and **Open snapshot**.
  **Find saves** remains the main entry point, alongside character selection.
- **Clearer guidance:** startup and discovery messages no longer recommend
  buttons that are not present.
- **Advanced access preserved:** pass a `characters-index` or snapshot path
  when launching the executable if automatic discovery cannot find your profile.
- **Better release notes:** releases now require committed notes for their exact
  version, with highlights, getting-started guidance, safety information,
  verification and documentation links. Missing notes stop publication.

All character, inventory, armor, YAML sharing, complete-character transfer,
progress reporting and backup safeguards from v0.0.1 remain available.
No save-format or gameplay-editing behavior changes in this patch.

## 🚀 Get started

1. Download **[the Windows x64 executable](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.2/enshrouded-character-editor-windows-x64.exe)**.
2. Launch it, click **Find saves**, and choose your character.
3. Review staged changes before saving. **Close Steam and Enshrouded before
   writing**; keep the Cloud setting appropriate to the opened profile.

No Python installation is required. For an explicit save path in PowerShell:

```powershell
.\enshrouded-character-editor-windows-x64.exe "C:\path\to\characters-index"
```

## 🛡️ Compatibility & safety

- **Windows x64**; verified editing rules still require your installed game.
- The executable is **unsigned**. Verify its
  **[SHA256 checksum](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.2/enshrouded-character-editor-windows-x64.exe.sha256)**
  and source before deciding whether to run it.
- Automatic backups, stale-source checks and guarded writes are unchanged.
- This remains an unofficial editor. In-game acceptance and Steam synchronization
  are not guaranteed by binary validation.
- Skill allocation/refunds, appearance editing and unsupported stateful-item
  creation remain unavailable. Snapshot inspection does not enable direct apply.

## ✅ Verification

The release workflow runs the complete synthetic regression suite, compiles
sources, and builds and smoke-tests the real executable before publication.
UI regression coverage checks that only **Find saves** remains in the toolbar,
that discovery still loads the active index, and that empty discovery provides
accurate guidance. Release-note checks require the exact version and all
reader-facing sections.
