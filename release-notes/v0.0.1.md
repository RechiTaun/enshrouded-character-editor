# Enshrouded Character Workshop · v0.0.1

**Your characters. Your inventory. Your adventure — with backups first.**

The first standalone release brings the local character editor together in a
portable Windows desktop application. Inspect your saves, make guarded edits,
and share complete characters without replacing the originals.

## ✨ Highlights

### Characters & progression
- **Multiple characters:** switch between characters in the same save independently.
- **Coherent level increases:** update both saved levels and XP using verified
  installed-game rules, granting **2 level-earned skill points per gained level**.
  Existing bonus rewards and learned skills are preserved.
- **Character names:** ordinary renames preserve the existing UTF-8 byte length.
- **Skill inspection:** view saved allocations and the earned, bonus, spent and
  available skill-point budget when rules are loaded.
- **Advanced knowledge inspection/editing:** filter existing raw progression
  values. These identifiers are not labeled quests or recipes.
- **Record explorer:** inspect appearance records and other saved data without
  pretending unsupported fields are editable.

### Inventory & armor
- **Searchable item picker:** select installed items through a filterable combobox.
- **Plain-item editing:** add stacks, edit quantities and remove supported plain stacks.
- **YAML inventory sharing:** export/import supported plain items; imports merge
  into the destination rather than replacing its whole inventory.
- **Supported armor creation:** select verified armor, level and rarity options.
  Fresh armor is added **unequipped**, with verified component initialization.
- **Automatic schema preparation:** generate missing supported armor component
  schemas from verified installed-game metadata when needed.

### Complete-character sharing
- Export a complete initialized character as an **`.enshrouded-character`** file.
- Preserve equipment, inventory, skills, appearance, knowledge and character-local
  exploration/quest data within the supported format.
- **Every import adds a fresh character identity** — never overwrites an existing one.
- Matching identities, names or saved gameplay prompt for a **different, unused name**.
  Import-time copy names can have different lengths and include Unicode.
- Cancelling import adds nothing; repeated imports can create independently named copies.
- Matching verified game builds are required. Character-local map data is retained,
  not rebound to a different world.

### Local-first safeguards
- **Find saves** discovers registered Steam and local save locations.
- Game rules load automatically from detected installations; a manual game-folder
  chooser is available when discovery is ambiguous or fails.
- Background preparation and an animated **progress bar** keep loading responsive.
- Review **staged changes** before saving, or discard them.
- Active-save writes require **automatic backups**, unchanged source files and
  closed Steam/game processes. Steam Cloud profile registrations are checked.
- Unchanged records and compressed frames are preserved; unsupported layouts
  fail explicitly instead of being guessed.
- No uploads, telemetry, game injection or automatic Steam Cloud changes.

## 🚀 Get started

1. Download **[the Windows x64 executable](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.1/enshrouded-character-editor-windows-x64.exe)**.
   No separate Python installation is needed.
2. Launch the editor and click **Find saves**, then select your character.
3. Make supported edits, review **Pending changes**, and save only when ready.
4. Keep Steam Cloud configured for the profile you opened; **close Steam and
   Enshrouded before writing**. The editor creates a backup.

This version also includes manual **Open active index** and **Open snapshot**
buttons. Later releases simplify this toolbar.

## 🛡️ Compatibility & safety

> This is an **unofficial editor for an undocumented, changing save format**.
> Automated roundtrip checks are not an in-game acceptance guarantee.

- **Windows x64**; installed Enshrouded files are required for verified editing rules.
- The executable is **unsigned**. SmartScreen may warn; verify the source and
  the accompanying **[SHA256 checksum](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.1/enshrouded-character-editor-windows-x64.exe.sha256)**.
  A checksum checks download integrity, not publisher identity.
- Skill allocation/refunds, appearance editing, level decreases and unsupported
  stateful/equipment creation remain blocked. Inventory YAML does not transfer armor.
- Older snapshots are inspectable, but direct active-save apply is disabled.
- Steam synchronization and edited-character behavior still require a backed-up
  in-game check. No game assets or personal saves are included.
