# Enshrouded Character Workshop · v0.0.3

**Apply your changes without tripping over yourself.**

This patch fixes direct apply refusing to save while the editor itself was
running, adds a complete user guide, and licenses the project under MIT.

## ✨ Highlights

- **Direct apply works from the executable again:** the running-game guard
  matched every process whose name started with `enshrouded`, including
  `enshrouded-character-editor-windows-x64.exe` itself, so saving always
  reported that Enshrouded was still open. The guard now checks only the exact
  Steam, game and dedicated-server processes (`steam`, `enshrouded`,
  `enshrouded_server`).
- **New user guide:** a step-by-step walkthrough of every tab, staged edits,
  character and inventory sharing, safe saving, backups, recovery and
  troubleshooting.
- **Friendlier README:** a focused getting-started page, with the original
  workflows, format research and validation notes preserved in a detailed
  reference.
- **Open source license:** the editor is now available under the MIT license.

No save-format or gameplay-editing behavior changes in this patch. All
features from v0.0.1 and v0.0.2 remain available.

## 🚀 Get started

1. Download **[the Windows x64 executable](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.3/enshrouded-character-editor-windows-x64.exe)**.
2. Launch it, click **Find saves**, and choose your character.
3. Review staged changes before saving. **Close Steam and Enshrouded before
   writing**; keep the Cloud setting appropriate to the opened profile.

Updating from an earlier version only requires replacing the executable.
No Python installation is required.

## 🛡️ Compatibility & safety

- **Windows x64**; verified editing rules still require your installed game.
- The executable is **unsigned**. Verify its
  **[SHA256 checksum](https://github.com/RechiTaun/enshrouded-character-editor/releases/download/v0.0.3/enshrouded-character-editor-windows-x64.exe.sha256)**
  and source before deciding whether to run it.
- Steam, Enshrouded and the dedicated server still block direct apply while
  running. Automatic backups, stale-source checks and guarded writes are
  unchanged.
- This remains an unofficial editor. In-game acceptance and Steam synchronization
  are not guaranteed by binary validation.
- Skill allocation/refunds, appearance editing and unsupported stateful-item
  creation remain unavailable. Snapshot inspection does not enable direct apply.

## ✅ Verification

The full synthetic regression suite (245 tests) passes locally on this source.
New coverage confirms that the editor's own executable no longer blocks direct
apply while the game and the dedicated server still do. The release
workflow reruns the suite, compiles sources, and builds and smoke-tests the
real executable before publication.
